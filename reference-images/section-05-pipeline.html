The Methodology

From raw directory to
analyst-ready intelligence.

A four-stage Python pipeline transforms the live YC Algolia directory into structured, searchable company intelligence. Each stage is modular — swap in your own NLP model, skip the LLM step, or run it headless in CI.

bash · zsh
# instant demo
$cd apps/web && npm run db:setup && npm run dev
# live pipeline
$npm run pipeline:import
Pipeline — 4 stages
01
SCRAPE_YC.PY
Pulls live YC directory via Algolia API. Captures batch, industry, team size, hiring status.
02
EXTRACT_ENTITIES.PY
Regex and optional spaCy NER extracts funding rounds, founders, and company entities.
03
SUMMARIZE.PY
OpenAI (optional) generates investor-ready profiles from raw extracted data.
04
IMPORT_TO_DB.PY
Loads structured JSON into SQLite via Drizzle ORM, ready for the dashboard.
modular · headless · ci-ready

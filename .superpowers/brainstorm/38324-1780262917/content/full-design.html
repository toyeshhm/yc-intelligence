The Methodology

From raw directory to
analyst-ready intelligence.

Four stages. Each is a standalone Python script — run individually or chain together with run_pipeline.py.

# instant demo
cd apps/web && npm run db:setup && npm run dev
# live pipeline
npm run pipeline:import
01
scrape_yc.py
Pulls live YC directory via Algolia API. Captures batch, industry, team size, hiring status.
02
extract_entities.py
Regex and optional spaCy NER extracts funding rounds, founders, and company entities.
03
summarize.py
OpenAI (optional) generates investor-ready profiles from raw extracted data.
04
import_to_db.py
Loads structured JSON into SQLite via Drizzle ORM, ready for the dashboard.

Design Notes
  • Palette: void black + forest green + aged gold
  • Type: Cormorant Garamond (display) + Libre Baskerville (body)
  • Nav: horizontal rule style, not pill/floating
  • Grid: asymmetric — no 3-equal-col grids
  • Bezel: double-border specimen boxes
  • Motion: stagger reveals, scrubbed parallax (GSAP)
  • Zero em-dashes, zero Inter, zero AI gradients
